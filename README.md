# atlas_ren

I build websites and small tools for everyday life — from personal web design to playful learning experiences.

你好，我是 atlas_ren。

这里记录我的网页设计与小工具实践：个人网站、儿童学习应用，以及方便家庭使用的活动页面。希望把日常里的小需求，做成清楚、好用、可以持续改进的作品。

---

## What I Build / 我在做什么

- **Web design** — 探索个人网站的视觉表达、内容组织与交互体验。
- **Learning through play** — 用声音、字母和触摸交互，制作适合孩子的学习小应用。
- **Everyday tools** — 把活动信息、行程与投票整理成便于浏览和分享的网页。

## How I Work / 我的实践

- 从身边具体的需求出发，把想法先做成可以使用的版本。
- 关注内容是否清楚、操作是否顺手，以及手机和平板上的体验。
- 在真实使用中持续调整，让小作品慢慢变得更完善。
